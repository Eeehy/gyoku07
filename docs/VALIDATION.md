## 最新：原创丝绸文字与流畅度调整（2026-10-09）

用户选择原创丝绸波纹，后续反馈帧率偏低，并明确要求动画默认播放、移除手动暂停。新增 `SilkText.tsx`；修改 Hero、Header、Experience 与首屏样式；无新增依赖、无个人数据更改。Architect Agent 审核方案，Tester Agent 只读审查状态和清理，父 Agent 实际浏览器验证。

已取消文字原 30fps 间隔判断，改为每次 rAF 绘制；切片 2px→3px，减少约三分之一单帧绘制调用；预计算波纹衰减。Cursor 静止时停止循环，移动后重新启动，缓动按 delta 计算。Header 在初始化 / resize 缓存真实 Hero 文档坐标，scroll 不读取几何。手动暂停按钮和状态已移除。

独立 Chrome 的文字图像采样：1.0123s 内 61 次采样、60 次内容变化，约 59 次更新 / 秒；初版 30fps 限制已不存在。另一次 2s 回调采样中首页回调约 60fps、95% 间隔 16.8ms，无超过 25ms 的间隔；组队区约 59fps，有一次超过 25ms 间隔。这是测试环境的回调 / 文字更新测量，不等同于用户设备或所有 GPU 的帧率保证。原视频保持素材的 30fps。

短时主线程 JS 执行采样：首页约 27→50ms / 2s，组队区约 6.3→4.5ms / 2s。更高文字绘制频率增加了总绘制工作，不能声称整页 CPU 必然下降；静止光标空转已减少，单帧切片量下降。

功能通过：默认播放、无播放 / 暂停 UI、鼠标 / 点击波纹、光标到位停止并可重新启动、离屏 Canvas 像素稳定与视频自动停止、回到首页恢复、浮动导航、320 / 390 / 958 / 1920px 无溢出、运行中切换减少动画移除视频与 Canvas、Canvas 失败显示原文。此前已确认原文可选择与手机轻触。最终构建通过，页面异常为 0。
