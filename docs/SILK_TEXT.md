# 简介丝绸文字：工程分析

范围：Hero 中用户选中的两句简介，保留字体、换行、字号、原有布局与联系方式。

用户参考 React Bits Pro Mesh Lettering，并明确选择原创丝绸波纹实现。官方接入需要授权和 registry 配置，当前项目未配置，故不安装或声称使用官方付费组件。

## 项目理解与方案

现有 React / TypeScript / Motion 单页中，Hero 简介为普通 DOM 文本，视频与导航独立。新增可复用 `SilkText.tsx`，局部 Canvas2D 绘制与连续小幅波纹；DOM 原文仍负责排版、文本选择和无障碍内容。无需路由、额外依赖或重新加载 Three.js。

数据流：原文 → DOM 的真实字体 / 换行位置 → 局部文字纹理 → 细切片形变与淡蓝高光；指针通过 ref 触发局部衰减波。低幅持续呼吸与主动交互分离。

## 风险与验收目标

Architect Agent 评估确认该局部方案合理：保留 DOM 作为唯一内容来源，先完成字体测量与首次绘制再显示装饰层，限制形变量和光照，控制帧循环并清理监听。实现为二维纹理形变，不描述为真实三维网格。

字体加载或响应式换行可能导致错位，因此按字体就绪和尺寸变化重建纹理。小字号不适合大幅扭曲，限制位移并维持亮度。Canvas / 字体处理失败时使用完整原文。减少动画不启用 Canvas；离屏与页面隐藏时停止 rAF；DPR≤1.5，不逐帧更新 React。用户反馈流畅度后，已取消最初 30fps 限制，按每次浏览器 rAF 更新时间和绘制。

验收：原文可读 / 可复制、桌面与手机无布局溢出、自然波纹与指针 / 点击反馈可见、自动停帧稳定、减少动画与 Canvas 失败降级、导航和 CTA 正常、构建通过。实现为原创轻量效果，不宣称与付费组件完全一致。

参考：[Mesh Lettering](https://pro.reactbits.dev/docs/components/mesh-lettering)、[官方安装要求](https://pro.reactbits.dev/docs/installation)。

## 实现与调节

`SilkText.tsx` 的 `text` 为原文，换行符决定显式分行，`mobileBreakAt` 追加手机断行。两句简介使用原字号，底层按 DOM Range 获取实际字位，不另行估算换行。波纹使用细切片和淡蓝高光，最大纵向位移 4px，默认微风约 1px；连续时间保留相位，暂停恢复不跳变。图形层在原文字边缘多留 6px，不改变页面布局。

鼠标移动和轻触只添加衰减波，不阻止选择或页面滚动。画布仅用于视觉，带 aria-hidden / pointer-events:none；原 DOM 保留可选择内容。减少动画或绘制失败时直接显示普通原文。

用户后续明确要求不提供手动暂停、默认播放，已移除暂停按钮及相关状态。视频与文字默认播放，离屏和页面隐藏时自动停止绘制 / 播放。原背景视频、主标题、CTA 与悬浮导航均保留。

## 流畅度调整

最初为降低开销将文字绘制限制在 30fps；固定间隔判断还可能跳过额外帧。现在每次 rAF 按实际 delta 更新时间，恢复时重置时间基准。切片从 2px 改为 3px，绘制宽度同步改为 3.2px，减少约三分之一每帧 drawImage 次数；波纹衰减和半径每帧预计算，避免在每片中重复计算。

Cursor 到位后停止 rAF，指针移动时重新启动，跟随缓动按时间计算。Header 只在初始化与 resize 时测量 Hero 结束位置，scroll 事件比较缓存数值，减少交错的布局读取。帧率与主线程耗时分别记录：提高绘制频率可能增加总绘制工作，不将它描述为总负载必然降低。

测试发现当前安装的 Motion `useReducedMotion` 保留首次读取的设置，不自动更新 Hook 状态；Hero 和 SilkText 改用现有 `useMedia` 订阅，使运行中切换系统减少动画也能移除视频 / Canvas 并显示静态内容。该结论来自已安装源码与实际浏览器复现。
