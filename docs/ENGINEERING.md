# 工程分析与架构决策

日期：2026-10-09；范围：第一阶段个人技术网站 MVP。

## 项目理解

目标是展示技术兴趣、作品与合作方向，让大学生愿意联系组队。空目录新建，使用用户指定的 React / Vite / TypeScript / Tailwind / Three.js / Motion / Lucide。上级 AI 工作系统仅作为规范参考，未修改其配置、数据库与核心接口。

数据流：`portfolio.ts` → 展示组件 / 终端 / 技能关联 / 邀请草稿。表单状态仅驻留浏览器内存。没有服务端或存储接口。

## 问题与优先级

P0：网站实际运行；核心介绍、项目与组队入口可操作；缺失资料明确标注。P1：首页视觉与 3D 空间、滚动、终端、详情、响应式及键盘操作。P2：真实资料持续补充、后续部署与实测性能优化。

涉及新建工程文件、独立内容配置、组件与样式。没有删除已有文件或修改重要配置。

## 架构评估与决策

Architect Agent 审核确认：配置驱动单页适合 MVP。使用页面锚点与原生 dialog，不引入路由、全局状态库或数据库。3D 独立懒加载，内容组件无需依赖 WebGL。终端只接受白名单命令；关联技术通过项目 ID 引用；邮箱未配置时生成草稿，不伪造消息发送。

实施分为：基础工程与内容配置 → 七个分区 → 独立 3D → 交互 → 视觉与响应式 → 浏览器验证与文档。

## 风险与后续

Three.js 包体积、持续渲染和移动设备性能是主要风险；限制 DPR、粒子数量、停止离屏渲染、减少动画与静态降级。缺失资料可能误导访客，因此个人信息、概念示例、竞赛兴趣、联系方式都明确标注。

真实邮件入口依赖用户补充邮箱，mailto 依赖访客配置邮件客户端。没有后端投递与持久化。第一阶段未提供真实项目素材或奖项，所以不声称已完成这些个人成果。

将展示内容与特效拆开；把实际联系能力和演示状态写清；优先验证用户能操作的流程；从浏览器截图和实际溢出检查判断布局，不只依赖构建成功。本文件作为项目内长期记录保留，未改动全局 Knowledge_Base 索引。

章节标题 StrokeText 接入沿用以上原则：官方 JS/CSS 原样保留，独立类型声明与布局包装处理中文、懒加载、失败降级；按需播放后卸载。原接入阶段曾关闭无人使用的 ScrollTrigger；2026-10-10 增加统一滚动编排后已取消全局关闭，局部组件只清自己的时间线。修改、评估与验证见 `STROKE_TEXT.md` 与 `EDITORIAL_MOTION.md`。

DitherVeil 肖像接入的经验：不能只依赖 React 错误边界处理图片和 WebGL 的异步故障。初始化资源清理需在创建时登记，正常卸载和初始化末尾抛错共用幂等 cleanup；不能等子 DOM 移除后再查询 canvas。官方源码原样归档，运行适配与测试记录见 `DITHER_VEIL.md`。

ParticleText 小标题接入：先读取官方 registry 和现有项目标题按钮，保持内容、结构及 dialog 数据流。Architect 建议缩小运动幅度、按 DOM 实际行采样、保留淡化原文，仅在交互时运行。Tester 审查发现清空 readiness 后部分旧行可能不重建，已使用统一 layout revision 使全部行一起重建。异步字体等待必须在卸载后取消构建，ready 要在首帧绘制成功后通知。方案、文件与限制见 `PARTICLE_TEXT.md`；验证见 `VALIDATION.md`。

CircularCarousel 接入：照片独立于履历和项目，新增 About / Projects 间的画廊。用户照片路径未传入，先使用明确演示标识的本站素材，真实配置保留为空。Architect / Tester 审核建议保持 CSS 3D、默认播放、手机静态路径，并修复 off + snap 已对齐时的空转；原版源码归档，运行版处理超时 / 旧闭包、主动导航播报和图片占位。测试发现字幕淡入阶段对比度过低，局部取消字幕透明度动画、提高计数可读性，保留卡片 rise 入场。图片数量和尺寸需要在真实素材到齐后复查；见 `CIRCULAR_CAROUSEL.md`。

DriftWall 替换（2026-10-09）：用户明确要求删除整个照片木马与六张网站照片，替换数字视觉图片墙。Architect 评估沿用配置驱动单页，独立 VisualWall + driftWall 数据，无核心架构调整。官方 JS/CSS 原样归档，运行版补充 enabled、装饰语义、图片占位与悬停不停修复。新素材为本站实际截图、标注的界面概念和既有数字艺术，不代表新增项目成果。五列共享六种图片，静态路径仅六图；外置真实项目 CTA，重复 tiles 不进入键盘顺序。移除旧运行代码及六张项目内照片副本，未改微信附件原件。只读 Tester 审查与独立浏览器验证通过；限制与文件说明见 `DRIFT_WALL.md`。照片木马文档作为历史保留。

ProfileCard 身份卡（2026-10-09）：用户提供实际头像并要求接入官方组件。Architect 评估仅替换左列身份块，保持资料配置和既有页面模块。保留原始头像，不裁切；上下文字之外独立方图区。重点修复官方document.hasFocus空转、root变量和.avatar冲突、miniavatar错误循环、触屏滚动及CSS动画可见性。Tester发现重入遗留leaveRAF，已取消旧检查。当前真实联系入口采用原生mailto链接，无控制台占位回调和假handle链接。构建与独立Chrome验证通过，说明见PROFILE_CARD.md。

共享Particles（2026-10-10）：用户要求覆盖Hero以下全部内容。Architect评估复用单场景、视口大小sticky背景，以同单位负margin抵消布局占位，前景独立z层；保持资料和交互模块。Tester发现项目区不透明底色遮挡，局部改透明渐变。浏览器证明native IO阈值事件ratio为0.009999999776482582而isIntersecting=true，手动>=.01重复比较导致重入未恢复，已依赖原生状态。55项回归验证包括同Canvas跨区引用、布局与真实交互；源代码与适配记录见CONTENT_PARTICLES.md。

影片展示（2026-10-10）：分析用户提供视频后，在Projects后增加配置驱动的MotionStudies章节，保持既有单页、履历与粒子架构。Architect确认按需源加载、同步用户手势play、实际onPlay协调另一播放器与原音轨保留。FFmpeg另生成web版与封面，不覆盖原片；较大96秒视频由276MB降为16.37MB。Tester提出封面消失后键盘焦点丢失和正常AbortError误报，已以activated后焦点转交、异常类型区分解决。初始video无src比仅preload=none更明确地避免视频资源请求；播放器原生controls负责进度/音量/全屏。浏览器实测两个文件实际解码、单播放器、native进度与全屏、错误重试及响应式通过。新文件/资源/配置/限制见MOTION_STUDIES.md。

统一编辑式动效（2026-10-10）：读取原 Hero / Header / Experience / 项目 / 描边后，Architect确认复用GSAP、保持原生滚动和局部遮罩；首屏3.2秒标识与遮幕、标题压缩归位，章节英文大标题先入场，再接内容与图片揭示。移除重复Motion/IO入场，原局部特效保留；无需新依赖或核心架构调整。Tester指出状态覆盖、will-change清理、过滤context引用累积与透明元素Tab可达性，均已修正。浏览器发现focusin结束祖先动画会让按下的按钮在pointerup前移位，改为按下期间保护、释放/取消/Tab解除；不使用任意时间阈值误拦后续程序聚焦。统一配置、分析、决策与限制沉淀在EDITORIAL_MOTION.md，开发与生产浏览器验证通过。

性能审查（2026-10-10）：先生产冷缓存采样、读取媒体/WebGL/监听/编排源码，Architect确认局部压缩、视频源与播放分离、已有RAF内合并事件和DPR限制。实测React挂载前deep未定位导致视频加载，About锚点又仅剩37px边缘仍解码；改layout定位、250ms可见源选择与15%阈值。高分屏Dither从≤2降至≤1.5并关闭depth，保持默认2px点阵；默认1.25方案因点阵取整不采用。Particles与Dither指针合并不增加新循环。Header缓存/passive和GSAP局部context无需重构，仅清理opening专用scroll监听。保留原文件副本、完整画质影片和默认播放；字体preload与CSS真实生产URL复用。Tester最终源码复审无必修项；原生DPR1.25仍有组件本身点阵取整偏差，不影响功能。原资源、优化量、复现脚本与真实GPU限制见PERFORMANCE_AUDIT.md。
