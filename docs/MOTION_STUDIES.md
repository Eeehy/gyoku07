## 工程分析与架构决定

现有页面是 React / Vite / TypeScript 单页，资料与展示逻辑分离，Hero 以下共用一个视口大小的粒子背景。15 秒 Eeehy 短片为品牌文字、抽象形态与节奏设计；96 秒视频为 Clawd 水彩音乐动画。它们适合独立的视觉实验展示，不据此推断新项目成果、竞赛奖项或软件使用经验。

Architect 只读评估通过：在 Projects 后、Skills 前新增 `#films`，主影片较宽，第二部向下错位，移动端纵排。不更改既有项目结构、履历或计数，无新依赖。标题复用 `SectionTitle`，保留描边效果；按钮使用现有淡蓝变量。该章节继续共享原粒子层，没有新增 Canvas。

## 交互与加载

- 初始播放器无 `src`，封面 lazy；访问首页或滚动经过影片区不请求影片主体。
- 点击封面时同步赋源并调用 `play()`，保留移动端用户手势。打开原生 controls / playsInline；主动播放保留声音，不自动播放或循环。
- `onPlay` 暂停另一部影片，避免两段音轨叠加。用户可正常播放、暂停、调整声音、拖动进度和全屏；普通滚动不会中断已选择的影片。
- 移除封面按钮后焦点转交给播放器。`play()` 被策略阻止时保留控件与提示；正常暂停导致的 `AbortError` 不误报故障。
- 源文件失败恢复封面并提供重试，原生错误后的 `load()` 重新读取资源；旁边箭头可在新标签单独打开网页视频版本。异步播放请求带尝试标记与连接检查。
- 减少动画设置禁用按钮缩放与章节文字动画，但不阻止用户主动观看视频。无新增全局暂停按钮。

Tester 只读审查提出焦点丢失与 AbortError 提示问题，均已修复。浏览器验证记录见 `VALIDATION.md`。

## 替换与扩展

`src/data/films.ts` 维护名称、类别、说明、时长、网页视频和封面路径；追加配置即可增加影片。播放器在 `src/components/MotionStudies.tsx`，比例和错位布局在同名 CSS。新增配置请同时更新实际时长和封面；推荐 H.264 / AAC、faststart 和 16:9。

当前未提供独立字幕 / 音频描述文件，不把片内烧录文字宣称为可访问字幕轨道；如需完整字幕，可后续在播放器补充 `<track>`。本次桌面与移动端模拟不代表所有真机、网络或硬件帧率。影片独立展示，不改变真实项目或竞赛计数。
